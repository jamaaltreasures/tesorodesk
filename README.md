# Tesoro Desk

Tesoro Desk site for tesorodesk.com.

The complete industrial geometry build of the Tesoro site, built November 20, 2026. This repository holds the static site files: index.html, css/industrial.css with panel types A to E, 27 individual sticker assets under img/stickers, fonts, and js.

Tesoro is the product for accessing and controlling a Mac from iPhone and Apple Watch. Jamaal Treasures is the parent brand.
